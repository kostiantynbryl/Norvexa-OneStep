# Roadmap

## 0.1.x — Local MVP stabilization

- UI and accessibility testing on phones and tablets;
- confirmation dialogs for destructive stage/step actions;
- editable reminder time;
- richer empty/error/loading states;
- database migration tests and additional unit coverage.

## 0.2.0 — Smart planning

- optional Norvexa API integration;
- server-generated structured plans with strict JSON validation;
- adaptive rescheduling;
- expanded local template library;
- Android home-screen widget;
- richer charts and weekly review.

## 0.3.0 — Account and synchronization

- optional sign-in;
- encrypted cloud backup and multi-device synchronization;
- subscription entitlement layer;
- conflict resolution and change history;
- voice goal creation and file attachments.

## Later

- shared plans;
- web companion application;
- calendar integration;
- goal template marketplace;
- tablet two-pane layout.
